03

Как считаем

Веса модели

params × 10⁹ × BPW / 8 / 2³⁰

В GiB. Для 4-bit используйте эффективный BPW из формата файла, а не ровно 4.

KV-cache

2 × L × Hkv × D × T × N × B / 2³⁰

L — слои, Hkv — KV-heads, D — head dimension, T — токены на запрос, N — запросы, B — байты на элемент. Предполагается стандартный плотный KV-cache.

Данные по архитектуре: Qwen2.5 32B · Llama 3.3 70B · vLLM KV-cache
